# آژند v0.5.0

اولین نسخه با حساب واقعی ساکنین و داده واقعی D1.

## ساکنین
- ورود با شماره موبایل + کد دسترسی ۶ رقمی
- نشست ۳۰ روزه
- مانده و شارژ واقعی واحد
- اعلانات واقعی
- هزینه‌های اخیر
- ثبت و پیگیری درخواست خدمات
- Android + PWA

## مدیریت
مسیر: `/manage`

با همان Setup Admin Key فعلی:
- ساخت عضو و واحد
- صدور/بازنشانی کد ورود
- ثبت شارژ
- انتشار اعلان
- آمار کلی

## امنیت
- کد دسترسی خام ذخیره نمی‌شود؛ Salt + SHA-256.
- Token نشست 256-bit است و فقط Hash آن در D1 ذخیره می‌شود.
- Rate limit برای ورود فعال است.
